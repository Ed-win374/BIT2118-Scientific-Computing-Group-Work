# BIT 2118 – Scientific Computing Group Work

This repository contains our BIT 2118 Scientific Computing coursework, including Python implementations of numerical and scientific-computing techniques and practical scenario extensions.

## Repository layout

- `code/` — scripts for Tasks 02–20.
- `figures/` — figures generated by selected scripts.
- `real_world_modifications/` — applied/real-world scenario scripts.

## Running the code

Install Python 3 and the libraries used in the scripts (NumPy, SciPy, and Matplotlib). From the project folder, run a script with:

```bash
python code/Task_02_numpy_arrays.py
```

Some scripts save figures into the `figures/` directory. Run them from the project root so figure paths resolve as expected.
